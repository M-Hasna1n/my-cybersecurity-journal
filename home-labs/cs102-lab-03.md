## Task 15: Operator Precedence and Parentheses Impact

### Description

This program highlights operator precedence in C arithmetic expressions. It compares $a + b \times c$ (where multiplication precedes addition) against $(a + b) \times c$ (where parentheses override default precedence).

### Code

```c
//Task 15
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[]) {

    int a, b, c, result1, result2;

    printf("Enter a number for val1:");
    scanf("%d",&a);
    printf("Enter a number for val2:");
    scanf("%d", &b);
    printf("Enter a number for val3:");
    scanf("%d", &c);

    result1 = a + b * c; //Multiplication before addition
    result2 = (a + b) * c; //Parenthesis before multiplication

    printf("The result are: \n");
    printf("Without parenthesis (a+b*c): %d\n", result1);
    printf("With parenthesis ((a+b)*c): %d\n", result2);
    return 0;
}

```

> **Image Placement Suggestion:** Insert the code screenshot (`task 15 code.png`) here.
> 
> 

### Output Explanation

For inputs $a = 1$, $b = 2$, $c = 3$:

* Without parentheses: $1 + (2 \times 3) = 7$

* With parentheses: $(1 + 2) \times 3 = 9$
